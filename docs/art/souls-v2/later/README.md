# Soul face sheets kept for a later update

Not cut into the game yet. To add one, move it up a folder, add it to `SOUL_SHEETS` in
`scripts/cut-art.py` with one kind letter per cell, and run `npm run art`.

- `s6-aliens.jpg`: 16 aliens (kind `x`). Unnamed souls could draw them, or give them tagged lines.
- `s7-pets2.jpg`: 16 more pets (kind `a`, faces a-17 to a-32), row by row: beagle, siamese cat,
  chihuahua, lop rabbit, green parrot, white mouse, shiba inu, persian cat, cockatiel, bearded
  dragon, dalmatian, ginger cat, axolotl, border collie, pet pig, french bulldog. Pet lines must be
  tagged with their face ("a-17|...").
