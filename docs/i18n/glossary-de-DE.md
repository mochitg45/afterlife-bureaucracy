## Localized (not literal)
- Candy Corn (Halloween currency): Candy Corn -> Kürbis-Bonbons (US-only candy; pumpkin sweets read instantly in DE)
- Painted Eggs (Easter currency): Bemalte Eier -> Ostereier (natural German word)
- PC LOAD LETTER printer gag (2 keys): "PC LOAD LETTER. Er weiß, was er getan hat." -> "Papierstau. Dabei ist gar kein Papier drin. ..." (the classic German-office printer lie)
- #31337 admin gags: hell queue.10 "Admin-Zugang bitte, ist für einen Freund" -> "Nur kurz Admin-Rechte, ist für 'nen Kumpel"; intake queue.17 "ein Glitch ... Admin-Zugang" -> "ein Systemfehler ... Admin-Rechte"
- Cloud Nine Staffing (3 strings): Wolke-Neun-Personaldienst -> Wolke-Sieben-Zeitarbeit (German idiom is Wolke Sieben; matches the existing achievement name)
- Santa's "checks it twice" (Saint Nick): "Prüft zweimal / Eigentlich dreimal. Es ist eine große Liste." -> "Prüft das Goldene Buch / Dreimal sogar. Es ist ein dickes Buch." (Nikolaus' Goldenes Buch)
- Gingerbread Man chase line: "Lauf, lauf, so schnell ..." -> "Rennt, so schnell die Formulare es erlauben. Fangen kann ihn trotzdem keiner." (English fairy tale, no DE counterpart)
- Lasso gag "Yee-haw" -> "Yiehaa" (2 strings)
- Mail van chase (5 animal queue lines): Postauto -> Paketwagen (Postauto is Swiss; DE dogs chase the parcel van)
- Lanyard -> Schlüsselband (5 strings: 4 perk names + reindeer flavor)
- Pull -> Ziehung (2 strings: "Erste Fünf-Sterne-Ziehung", pity text); Zug read as a chess move
- Hornträger-Kellner -> Trinkhorn-Kellner (2 strings; "Hornträger" is German slang for cuckold)
- Methalle-Truchsess -> Methallen-Truchsess (2 strings, grammar)
- Meerjungfrau-Notarin -> Meerjungfrauen-Notarin (grammar)
- Perlendes Drehkreuz -> Perlentor-Drehkreuz ("perlend" = bubbling; matches the memo)
- Pool-Wärter -> Pool-Betreuer (2 strings)
- Wasserkocher-Kopf-Sachbearbeiter -> Heißsporn-Sachbearbeiter (2 strings; shorter, idiomatic)
- Chocolatier-Sachbearbeiter -> Pralinen-Sachbearbeiter
