# iOS build

The iOS project is generated by Capacitor and committed under `ios/`. It is configured on Windows but can only be built on a Mac.

On a Mac with Xcode 15+ and CocoaPods:
- `npm run cap:sync:ios` builds the web app and copies it into `ios/App/App/public`.
- `cd ios/App && pod install` once after each plugin change.
- `npm run cap:open:ios` opens `App.xcworkspace`; select a team under Signing & Capabilities, then run on a simulator or device.

Settings already applied: bundle id `com.afterlifebureaucracy.game`, deployment target iOS 15.0, portrait only (iPhone and iPad), full-screen, dark launch background `#1B1915`, `contentInset: never` (the app pads with `env(safe-area-inset-*)`).
